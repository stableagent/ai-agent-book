# فصل ۱: مبانی AI Agent (Agent Fundamentals)

## ۱.۱ تعریف Agent و فرمول بنیادین

عامل هوش مصنوعی (AI Agent) یک سیستم نرم‌افزاری است که از مدل‌های زبانی بزرگ (LLM) به عنوان هسته استدلال و تصمیم‌گیری استفاده می‌کند و می‌تواند با درک محیط، برنامه‌ریزی، حفظ کانتکست و بکارگیری ابزارها، اهداف تعیین‌شده را به‌طور خودکار دنبال کند.

معادله کلیدی طراحی Agent عبارت است از:

$$\text{Agent} = \text{LLM} + \text{Context} + \text{Tools}$$

### اجزای اصلی معادله:

1. **مدل زبانی بزرگ (LLM):**
   مدل پایه مانند GPT-4، Claude یا DeepSeek به عنوان موتور استدلال عمل می‌کند.
2. **کانتکست (Context):**
   تمامی اطلاعاتی است که در زمان تصمیم‌گیری در اختیار مدل قرار می‌گیرد؛ شامل پرامپت سیستم، حافظه کوتاه مدت و بلندمدت و نتایج جستجو.
3. **ابزارها (Tools):**
   توابع و APIهایی که به عامل اجازه می‌دهند بر دنیای واقعی یا سیستم‌های نرم‌افزاری تاثیر بگذارد (مانند اجرای کد Python، جستجوی وب، خواندن فایل یا ارسال ایمیل).

## ۱.۲ مهندسی Harness (چارچوب اجرایی)

کنترل و هماهنگی رفتار Agent بر عهده محیط اجرایی یا **Harness** است. Harness مسئول مدیریت حلقه تفکر-عمل (ReAct loop)، مدیریت خطاها، محدود کردن تعداد فراخوانی‌ها و تأمین امنیت اجرای ابزارها می‌باشد.
